# 0009. 결과를 모르는 결제 요청은 202로 응답한다

## 2026-10-13 (적용 중)

### 배경

- 결제사 결과를 모르면 503(`PG_PAYMENT_UNKNOWN`)으로 응답한다
- 503은 "지금 처리할 수 없다"는 뜻이라 재시도를 부르지만, 실제로는 결제 건이 만들어졌고 결과만 모른다

### 결정

- 결과를 모르면 `PENDING` 결제를 202로 응답한다. 성공은 200, 거절은 4xx 그대로
- 202는 결제 건이 커밋된 뒤에만 나가므로, 받는 쪽은 결과 이벤트를 기다리면 된다(0008)

### 트레이드오프

- 얻는 것: 받는 쪽이 에러 코드가 아니라 응답 코드만으로 결제 건 유무를 안다
- 감수하는 것: 받는 쪽이 200과 202를 구분해야 한다
