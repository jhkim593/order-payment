# 0008. 결제가 확정되면 결과 이벤트를 발행한다

## 2026-10-12 (적용 중)

### 배경

- 결제 결과는 요청 응답으로만 전달된다
- 응답 뒤에 확정된 결과(확인 폴링, 수동 확정)는 전달할 길이 없다

### 결정

- 성공·실패 확정 시 같은 트랜잭션에서 아웃박스로 결과 이벤트를 발행한다
- 요청 응답 경로와 확인 폴링 경로 모두. `UNKNOWN`은 발행하지 않는다(0003)
- 어디서 확정되든 결과가 전달되고, 상태 변경과 이벤트가 함께 커밋돼 유실되지 않는다

### 트레이드오프

- 얻는 것: 받는 쪽이 결과를 알기 위해 조회할 필요가 없다
- 감수하는 것: 같은 결과가 응답과 이벤트로 두 번 전달돼 받는 쪽이 중복을 걸러야 한다
