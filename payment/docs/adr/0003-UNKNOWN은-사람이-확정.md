# 0003. UNKNOWN은 자동 복구하지 않고 사람이 확정한다

## 2026-10-04 (적용 중)

### 배경

- 결제사 응답을 끝내 확인하지 못하면 `UNKNOWN`으로 내려간다
- 이 상태를 자동 재시도할지, 주문에 알릴지 정해야 했다

### 결정

- 자동 재시도하지 않는다. 재시도하면 이중 환불 위험이 있다
- 주문에도 이벤트를 보내지 않는다. `UNKNOWN`은 실패가 아니라 결과 미확정이라 받는 쪽이 할 일이 없다
- 운영자에게 알리고, 사람이 결제사에서 확인한 뒤 수동 확정한다. 확정 시 기존 성공/실패 이벤트가 발행되어 주문이 평소 흐름으로 복귀한다
- 수동 확정 전이는 자동 경로와 구분되도록 `confirm*` 접두사를 쓴다

### 트레이드오프

- 얻는 것: 확정된 결론이 생긴 뒤에만 통지한다
- 감수하는 것: 수동 확정은 3시간 안에 해야 안전하다. 이후엔 결제사 멱등키가 만료돼 금액·시각으로 대조해야 한다
