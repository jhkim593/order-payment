# 결제 서비스 스펙

## 결과 확인 정책

결제를 요청하고 80초가 지나도 결과가 확정되지 않으면 결제사에 직접 상태를 확인한다. 이후에는 10초 간격으로 다시 확인한다.

확인은 결제와 취소 각각 최대 4번까지만 한다. 4번을 모두 쓰고도 결과를 확정하지 못하면 더 이상 자동으로 확인하지 않고 관리자에게 알린다.

확인은 상태를 묻는 것이지 결제나 취소를 다시 요청하는 것이 아니다. 결제사에 요청을 보내는 것은 처음 한 번뿐이다.

## 중복 확인 방지

서버가 여러 대로 늘어나도 같은 결제는 한 번에 한 대만 확인한다. 확인을 시작한 서버가 도중에 멈추면 10초 뒤 다른 서버가 이어받는다.

## 결제사가 거절한 경우

결제사가 결제나 취소를 거절하면 바로 실패로 처리한다.

## 결과를 확정하지 못한 경우

결제사가 명확한 답을 주지 않아 성공인지 실패인지 모르는 상태는 실패로 처리하지 않는다. 돈이 빠져나갔을 수도 있기 때문이다. 이 경우 주문에 결과를 알리지 않고 관리자에게만 알린다.

관리자가 결제사에서 실제 결과를 확인해 성공 또는 실패로 확정하면, 그때 주문에 결과가 전달된다.

## 부분 취소

주문에서 일부 상품만 취소할 수 있다. 취소 금액은 주문이 계산해서 결제에 전달하며, 결제는 남은 금액을 넘겨 취소할 수 없다.

**한 결제에 대해 취소는 한 번에 하나만 진행한다.** 앞선 취소가 아직 처리 중이거나 결과를 확정하지 못한 상태면 새로운 취소를 받지 않는다. 처리 중인 환불 금액이 확정되지 않은 상태에서 추가 환불을 허용하면 실제 결제 금액보다 많이 환불될 수 있기 때문이다.
