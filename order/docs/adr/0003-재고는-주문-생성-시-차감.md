# 0003. 재고는 주문 생성 시 차감하고 결제 실패·취소 성공 시 복원한다

## 2026-10-06 (적용 중)

### 배경

- 주문은 생성 → 결제 → 결과 수신 순으로 진행된다
- 어느 시점에 재고를 줄일지 정해야 했다

### 결정

- 주문 생성 시 재고를 차감한다. 하나라도 모자라면 주문 전체를 거절한다
- 결제 실패가 확정되면 차감한 재고를 복원한다
- 취소 성공이 확정되면 취소한 수량만큼 복원한다. 미확정 취소는 환불이 나갔을 수 있어 복원하지 않는다
- 결제 중 재고를 점유해야 같은 재고를 두 주문이 가져가지 않는다

### 트레이드오프

- 얻는 것: 결제는 성공했는데 재고가 없는 주문과 그 자동 환불 경로가 생기지 않는다
- 감수하는 것: 결제 실패나 취소 성공이 확정되지 않으면 재고가 돌아오지 않는다
