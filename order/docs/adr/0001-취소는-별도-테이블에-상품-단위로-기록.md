# 0001. 취소를 별도 테이블로 분리하고 상품 단위로 기록한다

## 2026-10-04 (적용 중)

### 배경

- 부분 취소를 하려면 어떤 상품을 몇 개 취소했는지, 그 취소가 어디까지 진행됐는지 알아야 한다
- `orders.status` 한 칸으로는 "일부만 취소됨"도, 취소 진행 중도 표현할 수 없다

### 결정

- `order_cancellation`(취소 건: 금액, 사유, 상태) + `order_product_cancellation`(포함된 주문 상품과 수량)
- 취소 1건이 여러 상품을 묶는다. 결제사 호출이 한 번이라 부분 성공을 사람이 풀 일이 없다
- `order_product_id`로 참조해 주문 당시 가격으로 취소 금액을 계산한다
- 처리 중 취소는 주문당 1건 — `order_cancellation (order_id) WHERE status = 'PENDING'` 부분 유니크 인덱스
- `order_product.quantity`는 남은 수량. 취소 성공 시에만 줄여 실패 때 되돌릴 것이 없다
- 가드는 `요청 수량 <= quantity`. 하나라도 넘으면 요청 전체 거절
- 실패는 상태만 `FAILED`. 미확정은 `PENDING`으로 남아 다음 취소를 막아, 환불이 나갔어도 같은 수량을 다시 취소할 수 없다
- `orders.status`에서 취소 관련 값을 뺀다

### 트레이드오프

- 얻는 것: 묶음 취소와 상품별 수량 가드를 SQL 제약으로 건다
- 감수하는 것: 원래 주문 수량은 남은 수량 + 성공한 취소 건 수량으로 계산해야 한다
